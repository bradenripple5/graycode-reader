Basic Fiducial Pattern

ArUco Pair Angle Wheel

This pattern uses paired ArUco fiducial markers as visual angle references. The reader detects marker IDs and corners, pairs each inner marker with its matching outer marker, draws a vector between them, and uses that vector plus the pair's fixed angle label to estimate which way is up in the camera view.
